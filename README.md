# ☀️ SOLAR SITE LAB

**데이터로 찾는 최적의 태양광 발전단지** — 신재생에너지과 학생을 위한 Streamlit 디지털 학습지입니다. 네 후보지를 비교하고, 자신이 정한 가중치로 점수를 계산한 뒤 최종 선정 근거와 성찰을 작성합니다.

### 주요 기능

- 에너지 그린·솔라 옐로를 적용한 연구소 대시보드, 카드형 탐구 질문과 사진형 학습 자료
- 문제를 풀기 전 사진과 비유로 익히는 4단계 이론 탐험, 가중치 스티커 체험, 이론 다시 보기
- 태양광 발전단지·평야·구릉지·해안·산업단지·전력망의 사진형 학습 이미지 6장
- 좌측 7개 미션 메뉴와 상단 작성 진행률, 학번·이름 입력 후 프로젝트 시작
- Q1~Q23 학습 활동, 후보지 데이터 표와 항목별 비교 그래프
- 5개 가중치 슬라이더와 합계 100% 검증, 자동 비율 환산·기본값 복원, 즉시 점수·순위 표시
- Plotly 비교 그래프와 항목별 기여점수 그래프, 선택한 후보지 강조
- 균형·발전량·환경 중심 실험 비교, 경사도 제한 및 연간 발전량 단순 추정
- 최초 예상과 최종 선택 비교, 선정 근거·문제점·해결 방안·학습 성찰 작성
- 전체 답변과 계산 결과를 담은 CSV·TXT, 그래프가 포함된 인쇄용 HTML 보고서 다운로드

### 라이트·다크모드 사용하기

사이드바의 **화면 모드**에서 `자동`, `라이트`, `다크`를 선택하세요. 자동 모드는 Streamlit의 테마 설정을 따릅니다. 배경, 카드, 제목, 입력란, 버튼, 차트의 글자와 배경이 함께 바뀌며 모드를 바꾸어도 작성한 답변은 유지됩니다. 작은 화면에서는 카드와 버튼을 세로로 배치합니다.

화면에서 **학번·이름 입력 → 프로젝트 시작하기 → 이론 탐험 4단계 → 미션 선택** 순서로 진행합니다. 도입 학습에서는 전기가 만들어지는 과정, 부지 조건, 전력망·환경, 가중치를 사진과 쉬운 비유로 익힙니다. 연습 슬라이더는 미션의 평가 가중치와 별개이며, 사이드바의 **이론 다시 보기**로 돌아가도 작성한 답변은 유지됩니다.

다음·이전 이야기, 다음·이전 미션, 사이드바로 화면을 이동하면 본문 맨 위로 자동 이동합니다. 답변을 입력하거나 슬라이더를 조절할 때는 현재 스크롤 위치를 유지합니다.

MISSION 4와 5에서 가중치를 바꾸면 합계가 100%일 때 바로 결과를 확인할 수 있습니다. **자동 100% 환산**은 입력한 비율을 정수 백분율로 바꾸며 반올림 잔여값은 마지막 항목에 반영합니다. 모든 항목이 0%이면 환산하지 않고 안내합니다.

사진형 이미지는 built-in `image_gen` 도구로 만든 **AI 생성 학습용 예시**로, 실제 후보지 조사 사진이 아닙니다. 인터넷에서 불러오지 않고 `assets/`의 로컬 파일을 사용합니다. 생성 방식과 전체 프롬프트는 [이미지 안내](assets/README.md)에 기록했습니다. PC·모바일의 본문 상단에는 고정 헤더 높이를 고려한 여백을 두어 제목이 가려지지 않도록 했습니다.

HTML 보고서는 브라우저에서 열고 **인쇄 → PDF로 저장**할 수 있습니다. 학생 답변은 현재 접속 세션에서만 유지되므로 새로고침하거나 서버를 재시작하기 전에 보고서를 저장하세요. 별도 로그인이나 데이터베이스는 사용하지 않습니다.

### 데이터와 계산 방법

후보지 자료는 모두 **수업용 가상 데이터**이며 `streamlit_app.py` 안에 정의되어 있습니다. 모든 후보지는 기본적인 법적 입지 요건을 충족한다고 가정합니다. 경사도 제한은 수업용 사업 조건입니다.

일사량·환경 수용성은 클수록, 토지 비용·경사도·전력망 거리는 작을수록 높은 점수를 받도록 최소–최대 정규화합니다. 최신 학습 지침에 따라 모든 후보의 값이 같으면 해당 항목은 모두 100점입니다. 환산점수에 가중치를 곱해 합산하며, 가중치 합계가 100%가 아니면 계산하지 않습니다. 제한 조건으로 후보가 제외되어도 원래 네 지역을 기준으로 정규화하고, 동점은 공동 순위로 표시합니다. 화면의 종합점수는 소수 첫째 자리까지 표시하며 계산에는 반올림 전 값을 사용합니다.

| 평가 기준 | 가중치 (일사량·토지비·경사도·전력망·환경) | 1위 | 종합점수 |
| --- | --- | --- | --- |
| 균형 평가 | 30·20·15·20·15% | A 내륙 평야 | 61.6점 |
| 발전량 중심 | 60·10·10·10·10% | B 구릉지 | 67.5점 |
| 환경 중심 | 10·20·15·10·45% | C 해안 저지 | 83.8점 |

위 결과는 경사도 제한을 적용하지 않았을 때의 값입니다. 점수는 후보 간 상대평가이며 실제 사업의 절대적 경제성을 의미하지 않습니다. 교사용 수업 운영 계획과 평가 배점은 앱 하단에서 확인할 수 있습니다.

### GitHub Codespaces에서 실습하기

Codespaces에서 제공하는 Python 환경을 그대로 사용합니다. 가상환경을 생성하거나 활성화하지 않고, Python 버전과 개발 환경 설정도 임의로 변경하지 않습니다.

프로젝트의 주요 파일은 다음과 같습니다.

- `streamlit_app.py`: 화면과 앱 기능을 구현하는 메인 파일
- `requirements.txt`: 프로젝트에서 사용하는 외부 패키지 목록 (`streamlit`, `pandas`, `plotly`)
- `assets/`: 학습용 이미지 6장과 생성 프롬프트 기록
- `data/gdp_data.csv`: 기존 GDP 예제 자료 (현재 앱에서는 사용하지 않음)
- `.devcontainer/devcontainer.json`: 기존 Codespaces 개발 환경 설정

1. 필요한 패키지가 설치되어 있지 않다면 터미널에서 설치합니다.

   ```bash
   python -m pip install -r requirements.txt
   ```

2. 앱을 실행합니다.

   ```bash
   python -m streamlit run streamlit_app.py
   ```

3. Codespaces의 **포트(Ports)** 탭에서 `8501` 포트의 **브라우저에서 열기**를 선택합니다. 앱을 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

앞으로 기능은 `streamlit_app.py`를 중심으로 구현하고, 불필요하게 파일이나 폴더를 나누지 않습니다. 패키지를 추가할 때는 필요한 패키지만 `python -m pip install 패키지명`으로 설치하고 `requirements.txt`에도 추가합니다. 전체 환경의 패키지를 일괄 기록하지 않습니다.
